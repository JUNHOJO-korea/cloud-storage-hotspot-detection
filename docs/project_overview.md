# Project Overview

This project detects load imbalance hotspots in cloud storage systems from multi-level monitoring data.

## Objectives

- identify persistent hotspot states at node and port levels
- move from point anomalies to event-level hotspot outputs
- preserve interpretability for operations and diagnosis
- extend the rule-based pipeline with metric learning

## Main Components

1. Unified long-table data modeling
2. Imbalance feature construction
3. Robust SPC for abnormal state detection
4. Hotspot event construction
5. Structured distance learning
6. Validation and comparative evaluation

## Current Implementation State

- research pipeline: notebook-first
- reusable package layer: partially extracted
- open-source scaffold: present
- production deployment: not yet complete
