# Code of Conduct

## Our Standard

We want this project to be a respectful and constructive place for research, engineering, and open collaboration.

Examples of positive behavior:

- giving actionable and respectful feedback
- assuming good intent while staying technically rigorous
- documenting decisions clearly
- helping others reproduce results

Examples of unacceptable behavior:

- harassment, insults, or personal attacks
- dismissive or bad-faith technical discussion
- publishing private data without permission
- intentionally misleading claims about experimental results

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributions that violate these standards.

## Scope

This applies to repository discussions, issues, pull requests, and related project communication.
