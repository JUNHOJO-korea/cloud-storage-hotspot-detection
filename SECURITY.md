# Security Policy

## Supported Scope

This repository contains research code and project scaffolding. It is not currently positioned as a production security product.

## Reporting a Vulnerability

If you discover a security issue in the package or repository automation:

1. Do not open a public issue with exploit details.
2. Report it privately to the maintainer first.
3. Include:
   - affected file or component
   - reproduction steps
   - impact assessment
   - suggested remediation if available

## Sensitive Data

Do not commit:

- private industrial monitoring data
- credentials or tokens
- internal infrastructure identifiers that should remain confidential
